# Business Card 

A simple and responsive **Business Card** project built using **HTML and CSS**. This project helped me practice the fundamentals of web design and learn how different CSS properties work together to create an attractive layout.

## 🛠️ Technologies Used
- **HTML5** – Structure and content
- **CSS3** – Styling and layout

## ✨ CSS Concepts Practiced
- `div` and `class` for organizing and styling elements
- `display: flex` for layout alignment
- `margin` and `padding` for spacing
- `border` and `border-radius` for styling
- `box-shadow` and text shadows for depth
- `animation` and transitions for visual effects
- Background colors, fonts, and other styling properties

## 🎯 Purpose
The goal of this project was to strengthen my HTML and CSS skills through hands-on practice while creating a visually appealing business card.

## 🚀 How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Explore the business card design.
